# Lab Themes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each of the eight labs a full themed world, entered through its own CRT → theme opening animation, without changing game logic.

**Architecture:** One scoped stylesheet (`body:has(.<root>)` per lab) plus self-hosted fonts and SVG art, linked from every page's `<head>` with a content-hashed filename. The only JS edit is five colour literals in the lab 06 canvas script. A Playwright harness served by a header-mimicking local server checks every lab.

**Tech Stack:** Static Next.js export (compiled), CSS (`:has`, custom properties, keyframes), fonttools `pyftsubset` for woff2 subsetting, Node 26, Playwright + @axe-core/playwright.

**Spec:** `docs/superpowers/specs/2026-09-27-lab-themes-design.md`

**Execution:** Native (user asked to start immediately; plan review waived by user).

## Global Constraints

- Game rules, scoring and daily seed unchanged; no game JS edits except lab 06 colour literals.
- CSP unchanged: every asset `'self'` (or `data:` for fonts/images); no CDN or Google Fonts requests at runtime.
- Every new or changed asset gets a new content-hashed filename (`.htaccess` caches for a year as `immutable`).
- WCAG AA contrast (4.5:1 text, 3:1 large text/UI); visible `:focus-visible`; tap targets ≥ 44 px; no horizontal scroll at 360 px.
- `prefers-reduced-motion: reduce` → no intro, no decorative loops.
- Intro 0.9–1.3 s, `pointer-events: none`, animates only transform/opacity/clip-path/filter, starts in CRT look.
- Budget: ≤ 150 KB extra per lab; shared stylesheet ≤ 60 KB uncompressed.
- Fonts: SIL OFL only, Latin subset, woff2.
- Tooling (`tools/`, `docs/`, `.backup/`, `CLAUDE.md`, `.ai-stack`, `.claude/`, `skills-lock.json`, `.git/`, `QA.md`) never uploaded.

## Review Focus

1. Client-side navigation from `/lab/` into a lab → theme and intro must apply exactly as on a direct load (tested in Task 1 harness, `soft-nav` case).
2. React hydration discarding the injected `<link>` → theme vanishes after hydration (harness checks theme after `networkidle` + 500 ms).
3. Phone width 390 px → themed decorations must not cause horizontal scroll (harness checks `scrollWidth <= innerWidth`).
4. Keyboard-only visitor → exit tab reachable and focus ring visible (harness checks tab is focusable and has non-`none` outline on focus).
5. Navigating from a lab back to `/lab/` or `/` → no theme leaks (harness checks `--lab-theme` empty and header visible on `/lab/`).


Hook for tests: every theme sets `--lab-theme: <slug>` on `body`. Slugs: 01 arena, 02 blueprint, 03 bureau, 04 forge, 05 siege, 06 green, 07 atelier, 08 noir.
